# Vanagram brand assets

The logo is a long-roof van on a blue tile with a dotted route under it (a start, a few stops and an amber finish). It is original artwork.
The SVG files in this folder are the **masters**; everything else the site ships is made from them by the generator in `src/`.

## Files

| File | What it is for |
| --- | --- |
| `icon.svg` | The master icon, 512 × 512, rounded tile with transparent corners. Source of `icon-192.png` and `icon-512.png`. |
| `icon-maskable.svg` | The same artwork on a full-bleed square, scaled into the central 80 % so any launcher mask (circle, squircle) keeps the van. Source of `icon-maskable-512.png`. |
| `favicon.svg` | The small-size icon, 32 × 32. It holds **two designs** and switches with a media query inside the SVG: the detailed 32 px one, and below 24 px of rendered width a pixel-grid 16 px one (a solid van, wheel stubs with a white hub pixel, a white route line) that stays sharp in a tab. It only switches when the file is used **as an image** (`<link rel="icon">`, `<img src>`), never inlined into a page. The top bar uses it as an `<img>` for that reason. Source of `favicon-16.png` and `favicon-32.png`; also copied to `public/favicon.svg`. |
| `logo-lockup-light.svg`, `logo-lockup-dark.svg` | The icon and the word "Vanagram" side by side (519 × 128), for the README and anywhere the name goes with the mark. Ink `#18212f` on light, `#e8edf4` on dark. Like the favicon it holds two icon designs and picks by height: the master icon from 64 px tall up, the small one below. The word is Inter SemiBold **turned into outlines**, so it needs no font. |
| `src/gen/apple-touch-icon.svg` | Generated by `build.cjs`: the master artwork on a full-bleed square (iOS rounds the corners itself). Source of `apple-touch-icon.png`. |
| `LICENSE-Inter.txt` | Inter's copyright line and the SIL Open Font License 1.1: the lockups' letters (and `src/wordmark-semibold.json`) are outlines of Inter SemiBold. |
| `preview-sheet.png` | Every asset on a light and a dark background, at 1:1 and enlarged. Made by `src/compose.cjs`; look at it after changing anything. |

What the site serves lives in [`public/`](../../public): `favicon.svg`, `favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png` (180),
`icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `og-image.png` (1200 × 630, the link preview) and `manifest.webmanifest`. The PNGs
are not kept here as well: the generator writes them straight into `public/`.

| Colour | Hex | Used for |
| --- | --- | --- |
| Tile blue | `#1a73e8` | The tile, and the cut-outs (windscreen, wheel rings) so they match it. The app's `--accent`. |
| Van black | `#0d1219` | The body and the tyres. The dark theme's page background. |
| White | `#ffffff` | The route dots, the hubs, the door handle. |
| Amber | `#f9ab00` | The head lamp and the finish of the route. |
| Ink | `#18212f` / `#e8edf4` | The word in the light / dark lockup (the app's `--text` in each theme). |

## Regenerating

You need Node.js and the repository's dependencies (`npm ci`: the scripts use Playwright's Chromium), and **Inter** installed as a system
font (the og-image's text and numbers are set in it).

```sh
node docs/brand/src/build.cjs    # the SVG masters, the favicon (also into public/) and the lockups
node docs/brand/src/raster.cjs   # favicon-16/32, apple-touch-icon, icon-192/512, icon-maskable-512  ->  public/
node docs/brand/src/compose.cjs  # public/og-image.png and docs/brand/preview-sheet.png
```

Run from a clean checkout, these reproduce the committed files (the SVGs byte for byte, the PNGs pixel for pixel). The scripts are `.cjs`
because the repository's `package.json` says `"type": "module"`. To change the artwork edit `src/lib.cjs` (the van, the route, the 32 px and
16 px designs, the lockup layout) and run the three scripts in that order. `tools/brand.test.ts` (run by `npm test`) checks that the files the
page and the manifest name exist at the size they say. The og-image's tagline is in `src/compose.cjs`.

The word's outlines are in `src/wordmark-semibold.json`. They come from `src/wordmark.py`, which shapes "Vanagram" with HarfBuzz (kerning on)
and dumps the glyph paths of Inter SemiBold with fontTools; you only need it to change the word or the weight (`pip install uharfbuzz
fonttools`, then `python3 docs/brand/src/wordmark.py`; `INTER_DIR` points to the folder with `Inter-SemiBold.otf`,
`/usr/share/fonts/opentype/inter` by default).
